READ THE EXPERIMENT

A comparison you
can inspect.

One shared starting point. The raw API generates the first page. Two branches independently review that exact draft and each get one revision. Reviewers receive fresh contexts.

Different review contracts. EGM uses comprehension and design-critic reviewers with basic citation checks. EGM + harness adds document-bound passage IDs and requires a concrete failure argument for serious issues. These are adaptations of our design-review runtime to HTML, not the full Google plugin.

A small experiment. One task and one trial show examples, not a general winner. The same model group is requested throughout; actual provider routes are recorded. The compared HTML is kept as generated, with no manual polish. A common preview wrapper isolates each page and blocks external requests.

Your preference stays here. Choosing a favorite changes only this page. There is no account, tracking, or server-side vote.
