# One brief. Three builds.

A static comparison of three Daymark task planners generated from one brief. The page initially hides the workflow names, lets visitors try each build and choose a favorite, then reveals the methods, measured effort, and review findings. Preferences stay in page memory.

## Run locally

From the repository root:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

Open <http://127.0.0.1:8765/buildoff/>. No installation, build step, API key, inference call, or Sites account is needed. Stop the server with Ctrl+C. Use the HTTP server rather than opening `index.html` directly; the comparison uses browser APIs available on localhost and HTTPS.

The original hosted [comparison page](https://webpage-buildoff-samsauhard.samsauhard.chatgpt.site/) may require ChatGPT sign-in and owner access. This public source runs independently of that hosted deployment.

## Three saved outputs

| Label | Workflow | Standalone source | Changes from the original |
| --- | --- | --- | --- |
| A | EGM | [egm.html](builds/egm.html) | [Diff](artifacts/egm-changes.diff.txt) |
| B | Direct API | [direct.html](builds/direct.html) | Original shared draft |
| C | EGM + grounded harness | [grounded.html](builds/grounded.html) | [Diff](artifacts/grounded-changes.diff.txt) |

The `builds/*.html` files preserve the generated bytes. Serve them at `/buildoff/builds/egm.html`, `/buildoff/builds/direct.html`, and `/buildoff/builds/grounded.html` to open each independently. The comparison renders the same HTML in a sandboxed iframe with a shared test bridge and a policy blocking external requests. Standalone files do not include that wrapper. The measured widths refer to the comparison iframe, not a complete audit of standalone pages on physical phones.

Click **Run interaction checks** on each version at desktop and mobile width. Click **Stress-test long title** for the separate exploratory case. Both reset the selected page. Switching versions also starts with fresh tasks.
