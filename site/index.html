03 / EGM + HARNESSGrounded

Require the evidence.

Add a stricter evidence contract to the same two EGM reviewer roles.

  1. 01
    Select a passage ID

    Python retrieves the cited text from the current document.

  2. 02
    Justify serious warnings

    Name an affected requirement and a concrete failure scenario.

  3. 03
    Reject invalid evidence

    Reject stale citations or incomplete arguments. Correct once, then fail visibly.

Measured: grounded EGM adapter.More inspectable arguments, with higher token usage and more correction calls in these runs.

THE TOKEN TRADEOFF

PLANTED BUG DETECTION

Why also compare two generic reviewers?

Adding another call can change results without EGM personas. On the six existing designs, two generic reviewers found 6/6 planted bugs using 35,329 tokens and 14 HTTP attempts. EGM also found 6/6 using 53,620 tokens: 51.8% more tokens, with no extra planted detection. Both arms had equal logical call counts, output limits, and correction allowances; actual compute and provider routes differed.

Which approach is better?+

The saved single-review baseline used the fewest tokens and found the same planted bugs. Grounded EGM produced fewer unsupported major warnings than original EGM, with more tokens, minor comments, and corrections. We have not established an overall winner or a raw-API-versus-harness uplift.

What does the harness demonstrably repair?+

In the original experiment, 20/24 distinct reviewer responses passed JSON and quote checks initially. Four corrections raised final compliance to 24/24: +16.7 percentage points. Generic and EGM arms both used this repair. Format compliance does not certify semantic correctness.

Does 100% planted detection mean no missed bugs?+

No. It covers only deliberately planted faults. Both EGM versions missed the additional retry-accounting flaw, and unsupported warnings remain. The grounded inventory control still needed attention after review.

Are these three different models?+

No. The experiments requested the gpt-oss-120b model group through a local API router using hosted Groq, Cloudflare, and OVH routes. EGM is a workflow; the harness is software around the calls. Provider routes and sampling can affect results.

What do 70 passing tests establish?+

They check harness behavior: context isolation, evidence validation, budgets, and failure handling. They do not establish model accuracy. This website displays recorded results and does not run live model calls.
